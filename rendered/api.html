API Documentation¶

All component and connection property equations derive from balance equations for fluid composition, mass flow and energy in regarding thermal as well as hydraulic state and thermodynamic fluid property equations respectively. Standard literature is for example [BoswirthB12, BS16, ELLW12] (german) [WE17] (english). Equations and properties from other sources are cited individually.
